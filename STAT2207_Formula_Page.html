1Describing Data with Graphs

Class width
w = (max − min)k
k = number of classes.
Class boundaries
BL = (Lk + Uk−1)2
Halfway between upper limit of one class and lower limit of next.
Class midpoint
m = (L + U)2
Also equals (BL + BU) / 2.
Relative frequency
rf = fn
Proportion of total in class.
Cumulative frequency
CFk = Σi=1k fi
Running total up to class k.
Grouped mean
̄x = Σf·m / Σf
Approximation using class midpoints.
Number of classes (Sturges)
k ≈ log2(n) + 1
Rule-of-thumb for sizing classes.
Percentile from ogive
Pp = value at (p100)(n+0.5)
Read horizontally from cumulative curve.

2Numerical Measures

Sample mean
̄x = Σxn
Arithmetic average.
Population mean
μ = ΣxN
When N is the entire population.
Weighted mean
̄xw = Σwixi / Σwi
Each value weighted by w.
Median
Odd n: middle value; Even n: avg of two middles
Position: (n+1)/2.
Mode
Most frequent value
May be 0, 1, or many.
Trimmed mean
Drop p% lowest & p% highest, average rest
Resistant to outliers.
Range
R = max − min
Simplest spread measure.
Sample variance
s² = Σ(x−̄x)² / (n−1)
n−1 (Bessel's correction).
Population variance
σ² = Σ(x−μ)² / N
Divisor is N.
Sample SD
s = √s²
Same units as data.
CV
CV = (s / ̄x) × 100%
Relative variability, unit-free.
Quartiles (exclusive)
Q1 position = (n+1)4; Q3 = 3(n+1)4
Lower and upper quartile.
IQR
IQR = Q3 − Q1
Middle 50% spread.
Outlier fences
Lower: Q1 − 1.5·IQR; Upper: Q3 + 1.5·IQR
1.5 × IQR rule.
Percentile (p-th)
Position Lp = (p100)(n+1)
Interpolate if non-integer.
Chebyshev
≥ (1 − 1/k²) within k SDs of mean
Any distribution. Looser bound.
Empirical Rule
~68% / 95% / 99.7% within 1/23 SD
For approximately bell-shaped only.
Five-number summary
{Min, Q1, Median, Q3, Max}
Basis of box plot.

3Bivariate Data

Sxy
Sxy = Σxy − n̄x̄y
Cross-product sum of squares.
Sxx
Sxx = Σx² − n̄x²
x sum of squares.
Syy
Syy = Σy² − n̄y²
y sum of squares.
Pearson r
r = Sxy / √(Sxx · Syy)
−1 ≤ r ≤ +1.
Slope b1
b1 = SSxySxx
Change in y per unit x.
Intercept b0
b0 = ̄y − b1̄x
Line passes through (̄x,̄y).
R²
R² = (Sxy)² / (Sxx · Syy)
Fraction of y's variation explained by x.
Residual
e = y − ŷ
Σe = 0 by least-squares property.
Predicted ŷ
ŷ = b0 + b1x
Reliable only within observed x-range.

4Probability & Distributions

Sample space
S = {all outcomes}
P(S) = 1.
Complement
P(A') = 1 − P(A)
Probability of "not A".
Addition rule
P(A∪B) = P(A) + P(B) − P(A∩B)
If mutually exclusive: P(A∪B) = P(A)+P(B).
Multiplication rule
P(A∩B) = P(A) · P(B|A)
If independent: P(A∩B) = P(A)P(B).
Conditional probability
P(A|B) = P(A∩B) / P(B)
Probability of A given B occurred.
Bayes' theorem
P(Bi|A) = P(Bi)P(A|Bi) / ΣP(Bj)P(A|Bj)
Updates prior with evidence.
Multiplication (counting)
n1 × n2 × … × nk
Independent choices.
Permutation P(n,r)
n! / (n−r)!
Order matters, no repeats.
Combination C(n,r)
n! / [r!(n−r)!]
Order doesn't matter.
E(X)
Σx · P(x)
Long-run average.
E(X²)
Σx² · P(x)
Used for variance.
Var(X)
E(X²) − [E(X)]²
Always non-negative.
SD(X)
√Var(X)
Same units as X.
Fair price
c = E(X) when win = profit
E(X) = 0 at fair price.

5Discrete Distributions

Binomial setup
n trials, p = P(success), independent
X = # successes.
Binomial P(X=k)
C(n,k) pk (1−p)n−k
k = 0, 1, …, n.
Binomial mean
μ = np
Expected count.
Binomial variance
σ² = np(1−p)
SD = √np(1−p).
Binomial CDF
P(X ≤ k) = Σi=0k P(X=i)
Use tables or summation.
Poisson setup
X ~ Poisson(λ), λ = avg rate
Events in fixed interval.
Poisson P(X=k)
e−λ λk / k!
k = 0, 1, 2, …
Poisson mean/var
μ = σ² = λ
Unique property.
Poisson as Binomial limit
λ = np, n→∞, p→0
Use when n large, p small.
Hypergeometric setup
N pop, K successes, n drawn without replacement
X = # successes in sample.
Hypergeometric P(X=k)
[C(K,k) · C(N−K, n−k)] / C(N, n)
k = max(0, n−N+K) to min(n, K).
Hypergeometric mean
μ = nKN
Same as binomial mean.
Hypergeometric variance
n · (K/N) · (1−K/N) · (N−n)/(N−1)
FPC factor adjusts for no replacement.
Geometric P(X=k)
(1−p)k−1 p
First success on trial k.
Negative binomial
C(k−1, r−1) pr (1−p)k−r
r-th success on trial k.

6The Normal Distribution

PDF
f(x) = Φ(x) = (1(σ√2π)) e−(x−μ)²/(2σ²)
Bell curve, symmetric about μ.
Z-score
z = (x − μ)σ
Standardize to N(0,1).
P(X < x)
= Φ(z) = P(Z < z)
From standard normal table.
P(a < X < b)
Φ(zb) − Φ(za)
Use two z-scores.
P(X > x)
1 − Φ(z)
Right-tail probability.
Inverse normal
x = μ + z · σ, z = Φ−1(p)
Find x for given percentile.
Central 90% interval
μ ± 1.645 σ
5% in each tail.
Central 95% interval
μ ± 1.96 σ
2.5% in each tail.
Central 99% interval
μ ± 2.576 σ
0.5% in each tail.
Normal approx to binomial
μ = np, σ = √np(1−p)
Valid when np ≥ 5, n(1−p) ≥ 5.
Continuity correction
P(X = k) ≈ P(k−0.5 < XN < k+0.5)
Improves approximation.
P(X ≤ k) approx
P(XN < k + 0.5)
Lower-tail.
P(X ≥ k) approx
P(XN > k − 0.5)
Upper-tail.
P(a ≤ X ≤ b) approx
P(a−0.5 < XN < b+0.5)
Inclusive bounds.

7Sampling Distributions

CLT for mean
̄X ∼ N(μ, σ²/n) for n ≥ 30
Any population shape.
SE of mean
σ̄X = σ / √n
Standard error of ̄X.
P(̄X < c)
P(Z < (c−μ)(s/√n))
Use when σ unknown: replace with s.
CLT for proportion
p̂ ∼ N(p, p(1−p)n) if np, n(1−p) ≥ 5
Sample proportion approx normal.
SE of proportion
σp̂ = √(p(1−p)n)
Standard error of p̂.
P(p̂ < k)
P(Z < (k−p)/√(p(1−p)n))
Use prior p if known.
Sample size for mean
n = (z · sE)²
z = zα/2 for confidence.
Sample size for proportion
n = z² · p(1−p) / E²
Use p = 0.5 for conservative n.
E margin of error
E = zα2 · (s / √n)
Half-width of CI.
95% z
z0.025 = 1.96
Most common.
99% z
z0.005 = 2.576
Higher confidence.
90% z
z0.05 = 1.645
Lower confidence.
FPC (finite population)
SEadj = SE × √((N−n)(N−1))
When n/N > 0.05.
Difference of means SE
√(σ1²/n1 + σ2²/n2)
Independent samples.
Difference of props SE
√(p̂1q̂1n1 + p̂2q̂2n2)
Two proportions.

14Chi-Square Tests

Chi-square statistic
χ² = Σ(Oi − Ei)²Ei
O = observed, E = expected counts.
df — goodness-of-fit
df = k − 1
k = number of categories.
df — contingency (r × c)
df = (r − 1)(c − 1)
r rows, c columns.
Expected count
Eij = (row totali) × (col totalj)grand total
Under the null of independence.
Test of homogeneity df
df = (r − 1)(c − 1)
Same formula as independence.
Multinomial test
χ² = Σ(Oi − Ei)²Ei, Ei = n pi
k categories, pi = hypothesized probability.
Rejection rule
Reject H0 if χ² > χ²α, df
Always upper-tail test.
Test statistic formula
χ² = n (ad − bc)²(a+b)(c+d)(a+c)(b+d)
Shortcut for 2 × 2 table only.
Continuity correction (2×2)
|ad − bc| − n/2 in numerator
Yates' correction — reduces χ².
Assumptions
All Ei ≥ 5 (combine if smaller)
Sample of independent observations.
Sample size guideline
n ≥ 5 × df
Quick rule for adequate expected counts.
Critical value (df=1, α=.05)
χ²0.05, 1 = 3.841
Most common.
Critical value (df=2, α=.05)
χ²0.05, 2 = 5.991
Common in 2 × 3 tables.
Critical value (df=3, α=.05)
χ²0.05, 3 = 7.815
For 2 × 4 or 4 × 2.
Critical value (df=4, α=.05)
χ²0.05, 4 = 9.488
For 2 × 5 or 3 × 3.
Critical value (α=.01)
χ²0.01, df from table
Stricter threshold.
