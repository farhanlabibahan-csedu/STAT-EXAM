Question 1 — Goodness-of-Fit (3 Categories)

Exercise 14.6  |  Marks: 6
Q 1 Ch. 14 · Goodness-of-Fit

Suppose that a response can fall into one of k = 3 categories with probabilities p1 = 0.4, p2 = 0.3, p3 = 0.3, and n = 300 responses produce these category counts:

Category123
Observed Count (Oi)1309872

Do the data provide sufficient evidence to indicate that the cell probabilities are different from those specified for the three categories? Use α = 0.05.

a.Hypotheses.

H0: p1 = 0.4, p2 = 0.3, p3 = 0.3 (data fit the specified probabilities).

Ha: At least one pi differs from the specified value.

b.Test statistic.

Under H0, expected counts are Ei = n pi:

Category123
Ei = npi300(0.4) = 120300(0.3) = 90300(0.3) = 90

X² = Σ ((Oi − Ei)²Ei)

= (130 − 120)²120 + (98 − 90)²90 + (72 − 90)²90

= 100120 + 6490 + 32490

= 0.833 + 0.711 + 3.600 = 5.144

c.Rejection region.

df = k − 1 = 2. Critical value: χ²0.05, 2 = 5.991.

Reject H0 if X² > 5.991.

d.Conclusion.

Since 5.144 < 5.991, do not reject H0. There is insufficient evidence to conclude that the cell probabilities differ from those specified. The data are consistent with the proposed distribution.

p-value ≈ P(χ²2 > 5.144) ≈ 0.0764 (between 0.05 and 0.10).
