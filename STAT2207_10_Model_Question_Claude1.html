(i) Binomial assumptions: fixed n (10), two outcomes, independent trials with constant p (0.04). Satisfied. X ~ Bin(10, 0.04).

(ii) P(X ≥ 2) = 1 − P(X = 0) − P(X = 1)

P(X = 0) = (0.96)10 = 0.6648

P(X = 1) = 10(0.04)(0.96)9 = 10(0.04)(0.7312) = 0.2770

P(X ≥ 2) = 1 − 0.6648 − 0.2770 = 0.0582

(iii) P(X ≤ 1) = 0.9418. Since P(X ≥ 2) = 0.0582 > 0.05, the event is not unusual.

(b)

Y ~ Poisson(λ = 4).

P(Y = 6) = e−4(4)6/6! = (0.01832)(4096)720 = 0.1042

(ii) P(Y ≤ 6) from Poisson CDF with λ = 4 = 0.8893.
P(Y > 6) = 1 − 0.8893 = 0.1107.

(iii) E(Y) = Var(Y) = λ = 4. They are equal (Poisson property).

(c)

Question 6 Ch. 6 · The Normal Probability Distribution (Enhanced)

(a) Exam scores are normally distributed with mean μ = 70 and standard deviation σ = 8. (i) State the probability density function symbolically. (ii) Find P(60 < X < 80). (iii) Find P(X < 55 or X > 85). [3]

(b) For the same exam-score distribution: (i) Find the 90th percentile. (ii) Find the 5th and 95th percentiles and interpret them as a central 90% probability interval. [3]

(c) A factory produces 500 laptops; historically 5% are defective. (i) State the normal approximation to the binomial with continuity correction. (ii) Estimate P(more than 30 are defective). (iii) Estimate P(at most 15 are defective). [4]

(a)

(i) PDF: f(x) = 1/(σ√(2π))·exp[−(x−μ)²/(2σ²)].
With μ = 70, σ = 8: f(x) = 1/(8√(2π))·exp[−(x−70)²/128].

(ii) z1 = (60−70)8 = −1.250; z2 = (80−70)8 = +1.250

P(60 < X < 80) = Φ(1.25) − Φ(−1.25) = 0.8944 − 0.1056 = 0.7888

(iii) z = (55−70)8 = −1.875; P(X < 55) = 0.0304

z = (85−70)8 = +1.875; P(X > 85) = 1 − 0.9696 = 0.0304

P(X < 55 or X > 85) = 0.0304 + 0.0304 = 0.0608

(b)

(i) 90th percentile: P(Z < z) = 0.90 ⇒ z = 1.282

x = 70 + 1.282(8) = 80.25

(ii) 5th percentile: z = −1.645 ⇒ x = 70 − 1.645(8) = 56.84

95th percentile: z = +1.645 ⇒ x = 70 + 1.645(8) = 83.16

Central 90% interval: (56.84, 83.16)

(c)

X ~ Bin(500, 0.05). Mean μ = np = 25; SD σ = √(23.75) = 4.873.

Check: np = 25 ≥ 5 and n(1−p) = 475 ≥ 5 ⇒ normal approximation valid.

(ii) P(X > 30) ≈ P(Z > (30.5 − 25)/4.873) = P(Z > 5.54.873) = P(Z > 1.129) = 1 − Φ(1.129) = 1 − 0.8706 = 0.1294.

(iii) P(X ≤ 15) ≈ P(Z ≤ (15.5 − 25)/4.873) = P(Z ≤ −9.54.873) = P(Z ≤ −1.949) = Φ(−1.949) = 0.0256.

Question 7 Ch. 7 · Sampling Distributions (Enhanced)

(a) A population has mean μ = 80 and standard deviation σ = 15. A random sample of n = 49 is drawn. (i) State the Central Limit Theorem and explain why it applies here. (ii) Identify the mean and standard error of the sampling distribution of ̄X. (iii) Find P(̄X > 84). [3]

(b) For the same population: (i) Find P(|̄X − μ| ≤ 3). (ii) Find the value of k such that P(̄X < μ − k) = 0.10. (iii) Comment on how the standard error changes if the sample size increases from 49 to 196. [3]

(c) In a market survey, the true proportion of customers preferring Brand A is p = 0.50. A random sample of n = 250 is taken. (i) Compute the mean and standard deviation of the sampling distribution of p̂. (ii) Find P(p̂ ≤ 0.45). (iii) How large a sample would be needed so that the SE of p̂ is at most 0.025? [4]

(a)

(i) CLT: for independent random samples of size n from a population with finite mean μ and SD σ, the sampling distribution of ̄X approaches normal as n → ∞, with mean μ and SE σ/√n. Rule of thumb: n ≥ 30. Here n = 49 ≥ 30 ⇒ CLT applies.

(ii) Mean of ̄X = μ = 80; SE = σ/√n = 15/√49 = 157 = 2.143.

(iii) z = (84 − 80)2.143 = 1.866; P(̄X > 84) = 1 − Φ(1.866) = 1 − 0.9690 = 0.0310

(b)

(i) z = 32.143 = 1.400

P(|̄X − μ| ≤ 3) = 2Φ(1.40) − 1 = 2(0.9192) − 1 = 0.8384

(ii) Need z such that P(Z < −z) = 0.10 ⇒ z = 1.282.

k = 1.282 × 2.143 = 2.747. So P(̄X < μ − 2.747) = 0.10.

(iii) n from 49 → 196 (factor 4): new SE = 2.143/√4 = 1.071. To halve the SE, you must quadruple the sample size.

(c)

(i) Mean of p̂ = p = 0.50

SD of p̂ = √(p(1−p)n) = √(0.25250) = √(0.001) = 0.03162

(ii) z = (0.45 − 0.50)0.03162 = −0.050.03162 = −1.581

P(p̂ ≤ 0.45) = Φ(−1.581) = 0.0569

(iii) Need √(0.25n) ≤ 0.025 ⇒ 0.25n ≤ 0.000625 ⇒ n ≥ 400

So at least n = 400 is required.

Question 7 Ch. 7 · Sampling Distributions (Comprehensive)

(a) A population has unknown mean μ and standard deviation σ = 12. A random sample of n = 36 is drawn. By the Central Limit Theorem, describe the sampling distribution of ̄X. Compute its mean and standard error. Then find: (i) P(̄X > μ + 3), (ii) P(̄X < μ − 4), (iii) P(|̄X − μ| ≤ 2). [3]

(b) The true proportion of voters favoring candidate A is p = 0.40. A random sample of n = 200 is taken. By the CLT, describe the sampling distribution of p̂. Compute its mean, SD, and find: (i) P(p̂ > 0.45), (ii) P(p̂ < 0.35), (iii) the value c such that P(p̂ > c) = 0.05. [3]

(c) Required sample size. (i) For estimating a population mean μ with margin of error E = 2 at 95% confidence, where σ is unknown but estimated by s = 10, find n. (ii) For estimating a proportion p with margin of error E = 0.04 at 95% confidence, using the conservative p = 0.5, find n. (iii) Comment on how each n would change if the confidence level increased to 99%. [4]

(a)

CLT for the sample mean: for a population with finite mean μ and finite standard deviation σ, the sampling distribution of ̄X is approximately normal with mean μ and standard error σ/√n, regardless of the shape of the population, provided n is sufficiently large (rule of thumb: n ≥ 30).

Here σ = 12, n = 36, so SE = 12 / √36 = 126 = 2.000.

(i) P(̄X > μ + 3) ↔ z = 32 = +1.50
P = 1 − Φ(1.50) = 1 − 0.9332 = 0.0668

(ii) P(̄X < μ − 4) ↔ z = −42 = −2.00
P = Φ(−2.00) = 0.0228

(iii) P(|̄X − μ| ≤ 2) = P(−2 ≤ ̄X − μ ≤ 2) ↔ z = ±1.00
P = 2Φ(1.00) − 1 = 2(0.8413) − 1 = 0.6826 (matches Empirical Rule within 1 SD).

(b)

CLT for the sample proportion: when np ≥ 5 and n(1−p) ≥ 5, the sampling distribution of p̂ is approximately normal with mean p and standard error √(p(1−p)n).

Check: np = 200(0.40) = 80 ≥ 5 ✓, n(1−p) = 120 ≥ 5 ✓.

Mean of p̂ = p = 0.40
SD = √(p(1−p)n) = √(0.40 × 0.60200) = √(0.24200) = √0.0012 = 0.03464

(i) P(p̂ > 0.45) ↔ z = (0.45 − 0.40)0.03464 = 0.050.03464 = +1.4434
P = 1 − Φ(1.4434) = 1 − 0.9255 = 0.0745

(ii) P(p̂ < 0.35) ↔ z = (0.35 − 0.40)0.03464 = −1.4434
P = Φ(−1.4434) = 0.0745 (symmetric).

(iii) Find c such that P(p̂ > c) = 0.05 ⇒ P(Z > z) = 0.05 ⇒ z = 1.645
c = p + z · SD = 0.40 + 1.645(0.03464) = 0.40 + 0.0570 = 0.4570

(c)

(i) Sample size for mean at 95% confidence with margin of error E = 2 and s = 10:
n = (zα/2 · sE)² = (1.96 · 102)² = (19.62)² = (9.8)² = 96.04 → round up to n = 97.

(ii) Sample size for proportion at 95% confidence with E = 0.04 and conservative p = 0.5:
n = zα2² · p(1−p) / E² = (1.96)² · (0.25) / (0.04)²
= 3.8416 × 0.250.0016 = 0.96040.0016 = 600.25 → round up to n = 601.

(iii) Effect of raising confidence to 99%: zα2 changes from 1.96 to 2.576. Since n is proportional to z², the new sample sizes are:

For proportion: n = (2.576)² · 0.25 / (0.04)² = 6.6358 × 0.250.0016 = 1.65890.0016 = 1036.83 ⇒ 1037 (up from 601, a 73% increase).

(a) A lot of N = 50 items contains K = 6 defectives. A sample of n = 8 is drawn without replacement. Find P(exactly 2 defectives), P(no defectives), P(at most 1 defective). Compare the hypergeometric result for P(exactly 2) with the binomial approximation. [4]

(c) A basketball player makes a free throw with probability p = 0.75 independently per shot.
